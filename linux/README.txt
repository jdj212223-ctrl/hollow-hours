HOLLOW HOURS for Linux (x86_64), SteamOS included (Steam Deck, Legion Go S...)

Play:
  1. Unzip this folder somewhere, for example ~/Games/hollow-hours
  2. Run ./hollow-hours (or double-click it)

On SteamOS (to play it in Game Mode with your controller):
  1. Hold the power button -> Switch to Desktop.
  2. Unpack this folder, for example to ~/Games/hollow-hours
  3. Open Steam -> Games -> "Add a Non-Steam Game to My Library..." -> Browse -> pick ~/Games/hollow-hours/hollow-hours
  4. Go back to Game Mode: Hollow Hours is in your library under Non-Steam.
  To type to the AIs: Steam + X opens the on-screen keyboard.

Controller:
  left stick walk, right stick look, A talk/use, X hide, Y 2D/3D, LT sneak,
  RB voice chat, RT radio, D-pad down sound on/off, View/Select = PANIC (everything stops)

Your login and settings are kept in ~/.local/share/hollow-hours (only you can read your login).
The real Claude characters need Claude Code installed (the `claude` command); otherwise they use a local model
(Ollama) or scripted lines.
