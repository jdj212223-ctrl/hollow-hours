HOLLOW HOURS for Windows (64-bit)

Play: unzip this folder, then double-click "Hollow Hours.exe".
Windows may say "Windows protected your PC" the first time (the game isn't signed yet):
click "More info" -> "Run anyway".

Controller: Xbox / PlayStation pads work. left stick walk, right stick look, A talk/use, X hide, Y 2D/3D,
LT sneak, RB voice chat, RT radio, D-pad down sound on/off, View = PANIC (everything stops).

Your login is kept in the Windows Credential Manager; settings in %APPDATA%\Hollow Hours.
The real Claude characters need Claude Code installed (the `claude` command); otherwise they use a local model
(Ollama) or scripted lines.
